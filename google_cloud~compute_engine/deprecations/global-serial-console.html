Global serial console gateway deprecation

Compute Engine offered a global serial console gateway to aid in troubleshooting malfunctioning virtual machine (VM) instances. The global gateway has been replaced by regional serial console gateways in each Google Cloud region. For more information, see Connecting to a serial console.

Shutdown schedule

The following table lists the shutdown schedule for the global serial console gateway.

Date Event
April 30, 2024 The global serial console gateway was deprecated.
April 30, 2025 The global serial console shutdown.
