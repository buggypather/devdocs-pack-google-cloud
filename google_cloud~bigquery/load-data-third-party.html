Load data using a third-party application

Partner connectors such as Informatica and Fivetran let you ingest data from external databases and cloud storage into BigQuery. Starting these third-party integrations from BigQuery helps you centralize external data for analysis without building custom ingestion pipelines.

Load data using Informatica

To load data using Informatica Data Loader, follow these steps:

  1. In the Google Cloud console, go to the BigQuery page.

    Go to BigQuery

  2. In the Data pane, click add Add data.

    The Add data dialog opens.

  3. Click a data source, for example, Amazon S3 or Google Cloud AlloyDB.

  4. Click the Informatica Data Loader solution card.

  5. If you agree to the terms in the You're leaving Google dialog, click Confirm.

  6. On the Informatica login page, sign in to your Informatica account.

  7. To load data into BigQuery, follow the steps in your Informatica account.
