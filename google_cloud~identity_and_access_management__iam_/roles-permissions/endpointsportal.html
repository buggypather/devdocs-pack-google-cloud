Cloud Endpoints Portal roles and permissions

This page lists the IAM roles and permissions for Cloud Endpoints Portal. To search through all roles and permissions, see the role and permission index.

Cloud Endpoints Portal roles

Cloud Endpoints Portal offers the following service agent roles. Service agent roles should only be granted to service agents.

Role Permissions

Endpoints Portal Service Agent

(roles/endpointsportal.serviceAgent)

Can access information about Endpoints services for consumer portal management, and can read Source Repositories for consumer portal custom content.

Warning: Do not grant service agent roles to any principals except service agents.

Cloud Endpoints Portal permissions

There are no IAM permissions for this service.
