Getting support

Paid Support

If you have a paid Google Cloud support plan always open support cases through the support console, as described in the create a support case documentation.

Get a Google Cloud support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see Cloud Customer Care.

File bugs or feature requests

You can suggest feature requests and report issues on our public issue tracker. This is a great place for gcloud CLI team members and the developer community to discuss and track implementations of features or resolution of bug fixes, as well as share workarounds and patches to the gcloud CLI. Be sure to toggle the 'Type' field to reflect the nature of the issue you're filing (such as Bug or Feature Request) to help make responses more efficient.
