This page lists the IAM roles and permissions for App Development Experience. To search through all roles and permissions, see the role and permission index.

App Development Experience roles

App Development Experience offers the following service agent roles. Service agent roles should only be granted to service agents.

Role Permissions

App Development Experience Service Agent

(roles/appdevelopmentexperience.serviceAgent)

Give the App Development Experience service agent access to Cloud Platform resources.

Warning: Do not grant service agent roles to any principals except service agents.
