Cloud Storage agent skills

Cloud Storage provides agent skills that can help your agent accomplish common tasks. Agents that use these skills can then accomplish tasks with higher fidelity than an agent without the skills.

Agent skills are a standardized way to give AI agents specific knowledge and instructions they can reuse. They contain resources like scripts, reference materials, and templates that help the agent complete tasks accurately and reliably. For more information about skills, see Agent Skills Overview.

The Cloud Storage basics skill

The Cloud Storage basics skill, google-cloud-storage-basics, contains instructions for completing basic tasks in Cloud Storage, such as storing, retrieving, and managing data as objects in buckets, with support for the Google Cloud CLI, APIs, client libraries, Terraform, and Model Context Protocol (MCP).

Install the Cloud Storage basics skill

To install the google-cloud-storage-basics skill, run the following command in your agentic client or terminal:

npx skills add google/skills --skill google-cloud-storage-basics

Cloud Storage basics reference files

The Cloud Storage basics agent skill includes several reference files that provide technical depth. These references let the skill execute functions or commands accurately by providing specific context to the underlying model. By default, the Cloud Storage basics skill includes the following reference files:

  • CLI and API usage
  • Cloud Client Libraries usage
  • Core concepts
  • Data management
  • Data transfer
  • Cloud Storage FUSE
  • High-performance storage
  • Infrastructure as code (IaC) usage
  • Model Context Protocol (MCP) usage
  • Storage Intelligence

The Cloud Storage bucket architect skill

The Cloud Storage bucket architect skill, google-cloud-storage-bucket-architect, contains instructions for designing and creating Cloud Storage buckets tailored to your workload (such as AI/ML, media hosting, archiving, backup, logging, or sensitive data). The skill validates project-level security settings and generates configurations using the Google Cloud CLI, REST APIs, Terraform, or client libraries.

Install the Cloud Storage bucket architect skill

To install the google-cloud-storage-bucket-architect skill, run the following command in your agentic client or terminal:

npx skills add google/skills --skill google-cloud-storage-bucket-architect

  • C++ SDK guide

The Cloud Storage FUSE skill

The Cloud Storage FUSE skill, google-cloud-storage-fuse, contains instructions for mounting Cloud Storage buckets as a POSIX file system with Cloud Storage FUSE, covering mount flag and cache tuning, performance diagnosis, and AI/ML and Google Kubernetes Engine (GKE) workload configurations.

Install the Cloud Storage FUSE skill

To install the google-cloud-storage-fuse skill, run the following command in your agentic client or terminal:

npx skills add google/skills --skill google-cloud-storage-fuse

Cloud Storage FUSE reference files

The Cloud Storage FUSE agent skill includes reference files that provide technical depth. By default, the Cloud Storage FUSE skill includes the following reference files:

  • Checkpoint and write safety
  • GKE training deployment
  • Performance and cost diagnosis
