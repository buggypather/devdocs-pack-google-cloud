Region availability overview

You can choose any available region for your Cloud SQL instance. The region you choose affects the Cloud SQL edition and machine series available for your instance.

When you can create a new instance, you must select a region for the instance. If you don't select a region when you create an instance, then the region is set to us-central1 by default.

For more information on the requirements and decisions you need to make prior to creating a new instance, see Plan and prepare overview.
