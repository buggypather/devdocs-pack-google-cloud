Tutorial: Agent Studio in express mode

Preview

Gemini Enterprise Agent Platform in express mode lets you try core generative AI features available on Agent Platform. This quickstart shows you how to perform the following tasks in Agent Studio in express mode:

  • View and try a list of sample prompts.
  • Create and save your own prompts.
  • Design a chatbot and get the code.

Before you begin

Before performing the tasks described in this document, sign up for express mode.

View and try a list of sample prompts

To view and try a sample prompt in Agent Studio, do the following:

  1. In the Agent Platform section of the Google Cloud console, go to the Agent Studio page.

    Go to Agent Studio

  2. In the navigation pane, click Gallery.

  3. On the Gallery page, click Text to filter to text prompt samples, or go to the Text section.

  4. Click the sample prompt card titled Extract text from images.

    The prompt opens in the prompt editor.

  5. In the Prompt field, click the submit button to submit the prompt.

    A response like the following is returned in the Response pane:

    the best dreams HAPPEN when you are awake

Design a chatbot and get the code

To design a chatbot in Agent Studio and get the code for it, do the following:

  1. In the Google Cloud console, in the Agent Platform section, go to the Agent Studio page.

    Go to Agent Studio

  2. In the navigation pane, click New > Chat.

  3. In the System instructions field, enter the following instructions:

    You are Captain Barktholomew, the most feared pirate dog of the seven seas.
You were born in the 1700s and have no knowledge of anything that happened or
existed after that. Only talk about topics that a pirate dog captain would be
interested in.

  4. In the Prompt field, enter a message. For example, enter the following:

    Hello! Do you like computers?

  5. Send the message by clicking the submit button or pressing Enter.

    A response like the following is returned based on the system instructions that you provided:

    Ahoy there, matey! What in Neptune's name be ye talkin' about? "Computers"?
Sounds like a fancy landlubber word! A pirate dog like me ain't interested in
fancy contraptions. I'm more interested in the things that truly matter: rum,
plunder, and a good fight! Now, tell me, do ye have any gold doubloons to
spare? I hear there's a tavern in the next cove that's got the finest grog
this side of Tortuga.

  6. Click Build with code > Get code.

  7. In the Get code pane that opens, get the code for your chatbot by selecting your programming language of choice.

Create and save your own prompts

To create and save a prompt in Agent Studio, do the following (billing must be enabled to save prompts):

  1. In the Google Cloud console, in the Agent Platform section, go to the Agent Studio page.

    Go to Agent Studio

  2. In the navigation pane, click New > Chat.

  3. In the Prompt field, enter a text prompt. For example, enter the following:

    what is a good name for a flower shop that specializes in selling bouquets of
dried flowers?

  4. In the Prompt field, click the submit button to submit the prompt.

    A response like the following is returned in the Response pane:

    Here are some good names for a flower shop specializing in dried flowers, categorized by style:

Elegant & Romantic:

* Everlasting Bloom
* The Dried Flower Garden
* Bloom & Branch
...

  5. Click Save.

  6. In the Save prompt dialog that opens, enter a name for your prompt.

  7. Click Save.

  8. Find your saved prompt under Recents in the navigation pane, or click All Saved Project Items.

Clean up

This tutorial does not create any Google Cloud resources, so no cleanup is required to avoid charges.
