Getting support

Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see Cloud Customer Care.

Get support from the community

Ask a question on Stack Overflow

Ask a question about IAM on Stack Overflow. Use the tag google-cloud-iam for questions about IAM.

Discuss IAM

Visit the Google Cloud Slack community to discuss IAM and other Google Cloud products. If you haven't already joined, use this form to sign up. For IAM, join the #iam channel.

File bugs or feature requests

From the IAM documentation click "Send feedback" near the top right of the page. This will open a feedback form. Your comments will be reviewed by the IAM team.
