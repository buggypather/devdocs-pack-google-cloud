Get started with Gemini 4

The first Gemini 4 model is Gemini 4 Argon (gemini-4-argon), Google's frontier model that excels at deep work in complex, real-world tasks across domains including coding, finance, legal, cybersecurity, and science.

This guide shows you how to make your first Gemini 4 request, describes what's new in Gemini 4, and explains what changes when you migrate from Gemini 3.1 Pro. For model-specific details, see the developer's guide to Gemini 4 Argon.

Quickstart

Before you begin, you must authenticate to Gemini Enterprise Agent Platform using an API key or application default credentials (ADC). See authentication methods for more information.

Install the Google Gen AI SDK

Upgrade to the latest google-genai SDK (>= 2.34.0 for Python, @google/genai >= 2.32.0 for JavaScript/TypeScript):

pip install --upgrade "google-genai>=2.34.0"

Set environment variables

Replace GOOGLE_CLOUD_PROJECT with your Google Cloud project ID. Gemini 4 Argon is available on the global endpoint and in the us and eu multi-regions:

export GOOGLE_CLOUD_PROJECT=GOOGLE_CLOUD_PROJECT
export GOOGLE_CLOUD_LOCATION=global
export GOOGLE_GENAI_USE_ENTERPRISE=True

Make your first request

Python

from google import genai

client = genai.Client()

response = client.models.generate_content(
    model="gemini-4-argon",
    contents="How does AI work?",
)
print(response.text)

REST

curl -X POST \
-H "Authorization: Bearer $(gcloud auth print-access-token)" \
-H "Content-Type: application/json" \
https://aiplatform.googleapis.com/v1/projects/PROJECT_ID/locations/global/publishers/google/models/gemini-4-argon:generateContent \
-d '{
  "contents": {
    "role": "USER",
    "parts": { "text": "How does AI work?" }
  }
}'

What's new in Gemini 4

Unified input and output token limit

Gemini 4 Argon has a unified 1,048,576-token limit that includes both input and output tokens (where output includes thinking, function calls, and the final response). Output can use up to 1,048,576 tokens minus your input tokens. By default, a single synchronous request generates up to 65,536 output tokens (or 32,768 tokens for non-streaming direct HTTP requests).

Long decodes

When a single turn requires more than 65,536 output tokens (or 32,768 tokens for non-streaming foreground calls), such as formal proofs, complex math or science problems, or multi-file code generation, Gemini 4 Argon supports long decodes up to 1,048,576 tokens (minus your input tokens) on both the Interactions API and GenerateContent (v1beta1). With the latest Google Gen AI SDK (google-genai >= 2.34.0 for Python, @google/genai >= 2.32.0 for JavaScript/TypeScript, Go >= 1.77.0, Java >= 1.80.0), setting max_output_tokens greater than 65,536 (or greater than 32,768 for non-streaming calls) automatically follows continuation_token across segments to return a single response or stream. On the Interactions API, you can also run server-managed asynchronous long decodes with background=true or chain continuation_token manually in stored (store=true) or stateless (store=false) loops.

Note: Known issue: Long decoding (continuation_token) on both the Interactions API and GenerateContent (generateContent and streamGenerateContent) is supported only in the v1beta1 API (not v1) on Agent Platform. The Google Gen AI SDK uses v1beta1 by default unless you explicitly set api_version='v1'; for direct REST calls, use the /v1beta1/ endpoint path.

For code samples, SDK version requirements, and implementation rules, see Long decodes in the developer's guide to Gemini 4 Argon.

Thinking levels

Use thinking_level to control how much the model reasons before it responds. Gemini 4 Argon supports LOW, MEDIUM (default on gemini-4-argon), and HIGH (default on gemini-4-argon-cyber-permissive):

from google import genai
from google.genai import types

client = genai.Client()

response = client.models.generate_content(
    model="gemini-4-argon",
    contents="Design a lock-free ring buffer in Rust for multi-producer, single-consumer telemetry ingestion.",
    config=types.GenerateContentConfig(
        thinking_config=types.ThinkingConfig(
            thinking_level=types.ThinkingLevel.HIGH,
        ),
    ),
)
print(response.text)

Implicit context caching

Gemini 4 Argon supports implicit caching for shared prompt prefixes of 4,096 tokens or more, with durable caching enabled by default. To benefit from it, put static content, such as a code repository or long documents, at the start of your prompt.

Agentic video understanding

Agentic video understanding is generally available. It's off by default: uploaded videos use media_processing="static". To turn it on, set media_processing to "agentic".

Sampling parameters

Gemini 4 Argon ignores custom values for temperature, top_p, and top_k, as recent Gemini 3 models do. To control output, use thinking_level and structured output (response_schema).

Migrate from Gemini 3.1 Pro

We recommend migrating from gemini-3.1-pro-preview to gemini-4-argon. The following behavior is different in Gemini 4 Argon:

Area Gemini 3.1 Pro Gemini 4 Argon What to do
Input and output token limits Separate input (1,048,576) and output (65,536) limits Unified 1,048,576-token limit across input and output (where output includes thinking, function calls, and the final response); 65,536-token default single-request output limit (32,768 tokens for non-streaming direct HTTP requests), extensible up to 1,048,576 tokens using long decodes Budget input and output together. Upgrade to the latest Google Gen AI SDK and set max_output_tokens greater than 65,536 (or use background=true or continuation_token in custom loops) on the Interactions API or GenerateContent for outputs over the single-request limit.
thinking_budget Mapped to a thinking level Returns an HTTP 400 error Use thinking_level.
thinking_level="MINIMAL" Supported Returns an HTTP 400 error Use LOW.
Explicit context caching Supported Not supported Remove cached_content references and put static content (4,096 tokens or more) at the start of your prompts.
Token billing A subset of tokens is billed Every token the model processes is billed, including thinking tokens and internal tool system instructions and function declarations when using grounding. Grounding with Google Search is still billed per query. Review your cost estimates.

To migrate from gemini-3.1-pro-preview, do the following:

  1. Change the model ID to gemini-4-argon and upgrade to the latest Google Gen AI SDK (google-genai >= 2.34.0 for Python, @google/genai >= 2.32.0 for JavaScript/TypeScript).
  2. Account for the unified 1,048,576-token input and output limit and the 65,536-token (or 32,768-token non-streaming foreground) single-request output cap (or configure long decodes for larger outputs on the Interactions API or GenerateContent).
  3. Replace thinking_budget and thinking_level="MINIMAL" with thinking_level set to LOW, MEDIUM, or HIGH.
  4. Remove explicit cached_content references.
  5. Remove temperature, top_p, and top_k, which have no effect.
