Deferred tier controls

The Deferred tier queues turns and persists their state on the global endpoint. In addition to the controls in the preceding table, the following controls apply to deferred model calls:

  • Supported: Cloud Audit Logs and FedRAMP High.
  • VPC-SC restriction: External mcp_server tools aren't allowed inside a VPC-SC perimeter.
  • Not supported: Stateless zero data retention (ZDR), DoD IL5, and ITAR. Deferred execution requires store=true, so setting store=false or enforcing the constraints/vertexai.disableAPIStorage organization policy fails with HTTP 400 ("code": "invalid_request").
