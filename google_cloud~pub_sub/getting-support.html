Getting support

Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see Cloud Customer Care.

Get support from the community

You have several options for engaging with the Pub/Sub community and the product team.

First, you can ask a question about Pub/Sub on Stack Overflow using tags google-cloud-pubsub and google-cloud-pubsub-lite.

Second, join the cloud-pubsub-discuss Google group to discuss Pub/Sub and receive Pub/Sub announcements and updates.

Third, you can also visit the Google Cloud Slack community to discuss Pub/Sub and other Google Cloud products. If you haven't already joined, use this form to sign up. For Pub/Sub, join the #pubsub channel.

File bugs or feature requests

If you have a feature request or find a bug, please submit it using one of these issue trackers:

  • Pub/Sub service
  • Pub/Sub Lite service

Your comments will be reviewed by the Pub/Sub team.
