Manage cross-region egress

This page describes how to use Storage Intelligence advisor to manage cross-region egress.

Cross-region egress occurs when applications transfer data from Cloud Storage buckets in one region to Google Cloud services in another region. Colocating your Google Cloud services and storage resources helps manage cross-region egress.

Storage Intelligence advisor displays the Spike in cross-region egress finding when cross-region egress increases above historical trends in your project, folder, or organization. A finding is an anomaly detected from your metrics that needs your attention. For an overview of Storage Intelligence advisor, see About Storage Intelligence advisor. For a full list of findings, see Findings reference catalog.

Thresholds that trigger a finding

Storage Intelligence analyzes historical data to establish a baseline for cross-region egress across your project, folder, or organization. Storage Intelligence advisor generates a finding when cross-region egress increases above this baseline over the last 24 hours.

Findings reflect the previous day's activity. For example, a spike occurring on Tuesday appears in Storage Intelligence advisor on Wednesday.

Respond to a finding

  1. View the finding details.

  2. Use the following table to select the recommended strategy for your scenario:

    Scenario Recommended action Details
    Data is frequently accessed from another region Colocate resources using bucket relocation Colocate storage with Google Cloud services to optimize performance and reduce cross-region egress costs. Bucket relocation helps you move an existing Cloud Storage bucket from one geographic location to another.
    Need to understand which data or access patterns are driving egress Investigate with Storage Insights datasets If you need more granular information about what is driving cross-region egress, use Storage Insights to export metadata to BigQuery to identify specific prefixes, objects, and access patterns.
    Note: Exporting data to BigQuery incurs costs. For details, see BigQuery Pricing.
