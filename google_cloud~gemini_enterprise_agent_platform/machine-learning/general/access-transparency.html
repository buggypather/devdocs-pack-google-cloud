Access Transparency in Agent Platform

This page provides an overview of the support Access Transparency provides for Agent Platform.

Overview

Access Transparency provides you with logs that capture the actions Google personnel take when accessing your content.

Cloud Audit Logs show when members of your organization access content in your Google Cloud projects. Similarly, Access Transparency provides logs of the actions taken by Google personnel.

You can enable Access Transparency for a Google Cloud project, if the project resides in an organization.

Supported services

Access Transparency supports the following Gemini Enterprise Agent Platform services:

  • Gemini Enterprise Agent Platform Colab Enterprise
  • Generative AI on Gemini Enterprise Agent Platform
  • AutoML training on Gemini Enterprise Agent Platform
  • Gemini Enterprise Agent Platform custom training
  • Agent Platform Feature Store
  • Model Monitoring on Gemini Enterprise Agent Platform
  • Gemini Enterprise Agent Platform Pipelines
  • Gemini Enterprise Agent Platform Inference
  • Vector Search on Gemini Enterprise Agent Platform
  • Vertex AI TensorBoard
  • Gemini Enterprise Agent Platform Workbench instances
  • Vertex Explainable AI
  • Gemini Enterprise Agent Platform ML Metadata
  • Agent Platform Vizier
  • Agent Runtime on Gemini Enterprise Agent Platform
  • Gemini Enterprise Agent Platform model tuning

Limitations of Access Transparency in Agent Platform

All access to your data in Gemini Enterprise Agent Platform by Google personnel is logged, except for the following scenarios:

  • Scenarios where Access Transparency logs are excluded in all supported Google Cloud services
  • Using custom containers to serve online inference or batch inference requests from custom-trained models
  • Using Vertex Explainable AI with custom containers
  • Using AutoML forecasting-related resources such as forecasting datasets and forecasting models.
  • Using the following components:
    • Agent Platform Vizier
    • RAG Engine on Gemini Enterprise Agent Platform
    • Agent Retrieval on Gemini Enterprise Agent Platform
