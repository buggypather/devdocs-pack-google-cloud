30-day introductory trial for Storage Intelligence

The 30-day introductory trial for Storage Intelligence lets you evaluate, organize, and manage your Cloud Storage data at scale. The trial helps you identify optimization opportunities, analyze data, relocate buckets, and automate bulk object operations.

During the trial, you can use Storage Intelligence features in the following ways:

Action Description
Get resource metadata with Storage Insights datasets Create datasets of metadata and activity data for your Cloud Storage resources.
Export resource metadata to BigQuery Export metadata for your Cloud Storage resources to BigQuery for analysis.
Analyze storage with Gemini Cloud Assist Get AI-powered insights about your data storage landscape.
Generate inventory reports Generate lists of objects and their metadata for analysis.
Relocate buckets Relocate buckets across geographic locations.
Automate object operations at scale Perform operations on millions or billions of objects using batch operations.

Trial overview

You can use the 30-day introductory trial to explore Storage Intelligence and analyze your storage data for up to 30 days. You can enable the TRIAL tier using the Google Cloud console, Google Cloud CLI, or REST APIs. After activation, you can use the trial to create Storage Insights datasets, get data insights with Gemini assistance, relocate buckets, and run storage batch operations. For pricing details, see Storage Intelligence pricing.

The following table provides information about the 30-day introductory trial for Storage Intelligence:

Eligibility

You're eligible to configure the TRIAL tier for Storage Intelligence once for every organization, folder, and project for a 30-day period. If you enable the TRIAL tier for an organization, then all its folders and projects inherit the TRIAL tier. However, if you have enabled the STANDARD tier at any of these nodes, then you are no longer eligible for the introductory TRIAL offer.
Storage Intelligence tiers

A TRIAL tier enables the STANDARD tier features, such as Storage Insights datasets, bucket relocation, and storage batch operations. The TRIAL tier defaults to the STANDARD tier at the end of the 30-day period. If you don't want to use the STANDARD tier, you can disable the TRIAL tier at any time within the 30-day period.
Initiation

You can set the Storage Intelligence configuration to the TRIAL tier using the Google Cloud console, Google Cloud CLI, or REST API. To initiate the TRIAL tier, you'll need the Storage Admin role with the following permissions:

  • storage.intelligenceConfigs.update
  • storageinsights.datasetConfigs.create
Duration

Your introductory trial ends when one of the following occurs:

  • 30 days have elapsed since you initiated the trial.
  • You upgrade your TRIAL tier to the paid STANDARD tier.
  • You disable the TRIAL tier on the organization, project, or folder it was enabled on.

If you don't disable your TRIAL tier after the 30-day introductory trial period, the tier is upgraded to the STANDARD tier and charges are applied in the same project where the buckets and objects are stored. Existing datasets are not removed automatically and they continue to incur storage charges until you delete them. If you terminate the use of the Storage Intelligence STANDARD tier within 30 days of activation, you incur an early termination fee for the remaining duration.
Service level agreement (SLA)

SLAs might be limited during the trial period. The STANDARD tier SLAs can be activated at any time by upgrading the tier. You can activate the STANDARD tier SLA by upgrading the tier at any time during the trial period.

For continuous access to the Storage Intelligence features beyond the trial period, you can enable the STANDARD tier. For more information about the Storage Intelligence STANDARD tier, see Overview of Storage Intelligence.

Dashboard template

The Storage Intelligence dashboard is a template that provides the insights you can gain from Storage Insights datasets. You can use the template to begin building dashboards and visualizations customized for your specific needs. For setup instructions, see Storage Intelligence dashboard connection instructions.

Note: Visualizing data can consume significant BigQuery compute resources, especially when working with large datasets. To manage resource usage during evaluation, use a smaller representative dataset. A smaller dataset minimizes costs while allowing exploration of the dashboard and its insights. After exploring the smaller dataset, analyze larger datasets as needed.

Pricing

During your trial, we don't charge you the Storage Intelligence object management fee for all objects within the trial's scope. However, the storage and query charges still apply. For full pricing details, see the Storage Intelligence pricing page.

Limitations

The 30-day introductory trial for Storage Intelligence has the following limitations:

  • You can activate this trial only once for a specific organization, folder, or project.
  • Once activated for an organization, folder, or project, the trial period lasts for 30 days.
  • SLAs might be limited during the trial period.
  • Google Cloud can discontinue the trial at any time.
