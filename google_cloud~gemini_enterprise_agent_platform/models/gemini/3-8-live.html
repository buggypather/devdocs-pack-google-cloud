Gemini 3.8 Live

Gemini 3.8 Live is a real-time conversational model for low-latency, bidirectional voice and video interactions through the Gemini Live API. 3.8 Live supports dynamic multilingual switching, affective dialogue, proactive audio, function calling, and synchronized Live Avatar video synthesis.

You can configure speech output using any of the 30 prebuilt HD voices (prebuilt_voice_config) or a per-session custom voice sample (replicated_voice_config). For the list of supported voices and languages, see Configure language and voice.

Concurrent session quotas

When you use Gemini 3.8 Live (gemini-3.8-live), concurrent session quotas apply to both Gemini Live API sessions and Live Avatar sessions. Concurrent session quotas are checked when a session starts, so these limits apply whether you use Standard pay-as-you-go (Standard PayGo) or Provisioned Throughput.

To view the specific concurrent session limits for your project, do the following:

  1. In the Google Cloud console, go to the Quotas and System Limits page.

    Go to Quotas and System Limits

  2. In the Filter field, enter gemini-3.8-live and press Enter to view the concurrent session limits for your project.
