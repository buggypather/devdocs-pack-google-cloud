Firebase Mods roles and permissions

This page lists the IAM roles and permissions for Firebase Mods. To search through all roles and permissions, see the role and permission index.

Firebase Mods roles

Firebase Mods offers the following service agent roles. Service agent roles should only be granted to service agents.

Role Permissions

Firebase Extensions API Service Agent

(roles/firebasemods.serviceAgent)

Grants Firebase Extensions API Service Account access to manage resources.

Warning: Do not grant service agent roles to any principals except service agents.
