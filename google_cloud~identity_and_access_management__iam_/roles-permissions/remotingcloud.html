Remoting Cloud roles and permissions

This page lists the IAM roles and permissions for Remoting Cloud. To search through all roles and permissions, see the role and permission index.

Remoting Cloud roles

Remoting Cloud offers the following service agent roles. Service agent roles should only be granted to service agents.

Role Permissions

Remoting Cloud Service Agent

(roles/remotingcloud.serviceAgent)

Grants Chrome Remote Desktop Service Agent access to Google Compute Engine metadata.

Warning: Do not grant service agent roles to any principals except service agents.

compute.instanceSettings.get

compute.instances.get

compute.projects.get

Remoting Cloud permissions

There are no IAM permissions for this service.
