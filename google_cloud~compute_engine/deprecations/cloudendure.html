CloudEndure deprecation

CloudEndure was a third-party tool for migrating VMs to Compute Engine from other VM platforms. CloudEndure was deprecated as a migration tool on January 30, 2019. To migrate VMs, use Google's Migrate to VMs.

For information on Migrate to VMs, see the Migrate to VMs documentation.

Shutdown schedule

The following table lists the shutdown schedule for CloudEndure.

Date Event
