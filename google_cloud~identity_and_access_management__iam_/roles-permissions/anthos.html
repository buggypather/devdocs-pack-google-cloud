This page lists the IAM roles and permissions for Anthos. To search through all roles and permissions, see the role and permission index.

Anthos roles

Anthos offers the following service agent roles. Service agent roles should only be granted to service agents.

Role Permissions

Anthos Service Agent

(roles/anthos.serviceAgent)

Gives the Anthos service agent access to Google Cloud resources.

Warning: Do not grant service agent roles to any principals except service agents.
