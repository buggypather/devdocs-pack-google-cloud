v0.1 and v1beta1 metadata server endpoints deprecation

Compute Engine instances store crucial metadata on a metadata server. You use this metadata to inspect, manage, and troubleshoot your resources. To retain access to this information and maintain functionality for your applications, you must migrate from the deprecated v0.1 and v1beta1 metadata server endpoints to the v1 endpoint. Google Cloud shut down the v0.1 and v1beta1 endpoints on September 30, 2020. This document provides important information about this deprecation and guides you through the necessary migration steps.

Shutdown schedule

The following table lists the shutdown schedule for v0.1 and v1beta1 metadata server endpoints.

Date Event
September 30, 2019 v0.1 and v1beta1 metadata server endpoints were deprecated.
September 30, 2020 v0.1 and v1beta1 metadata server endpoints were shutdown.
