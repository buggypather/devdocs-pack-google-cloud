RHEL end of support

Red Hat Enterprise Linux (RHEL) operating systems reaching end of support (EOS) can expose your projects to security risks. This document explains the EOS process and provides migration paths to supported RHEL versions on Google Cloud. For a list of supported RHEL OS versions, see GA RHEL versions.

EOS versions

  • RHEL 7: EOS on June 30, 2024.
  • RHEL 6: EOL on November 30, 2020.

How will this EOS impact my existing virtual machine (VM) instances

Your current VMs that are running the EOS versions are not affected. After the EOS date, you can still start or stop your existing VMs that are using these images.

However, your projects might be at risk because you are running a version of RHEL that is no longer receiving security updates.

What do I need to know

After this date, the following changes take effect:

  • EOS RHEL versions are still available but are marked as deprecated.
  • For your existing PAYG RHEL VMs that use an EOS version, limited technical support is available through Google Cloud.

What do I need to do

  1. Review the lifecycle stage documentation.
  2. If you need to create VMs that use any of these EOS versions after the EOS date, make copies of the images that are available in your projects.
  3. Plan and migrate your workloads and applications to RHEL 8. Or, if you want to continue using the EOS RHEL versions, see Appending RHEL ELS licenses.
