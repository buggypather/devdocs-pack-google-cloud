Getting support

Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see Cloud Customer Care.

Get support from the community

Ask a question on Stack Overflow

Ask a question about Firestore on Stack Overflow. Use the tag google-cloud-firestore for questions about Firestore. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

Discuss Firestore

You can visit the Google Cloud Slack community to discuss Firestore and other Google Cloud products. If you haven't already joined, use this form to sign up. For Firestore, join the #firestore channel.
