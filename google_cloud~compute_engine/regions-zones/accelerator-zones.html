GPU locations

Accelerators, such as Graphics Processing Units (GPUs), are specialized hardware components that can significantly speed up machine learning and high performance computing workloads. When you create Compute Engine (VM) instances or other resources on Google Cloud, you can attach accelerators to them. For an overview of GPUs, see the GPUs on Compute Engine documentation.

The availability of specific GPU models varies by region and zone. This document provides a comprehensive list of accelerator availability to help you plan your deployments and select the appropriate locations for your resources.

This document focuses on accelerator availability for Compute Engine, Google Kubernetes Engine (GKE), and AI Hypercomputer. If you use GPUs with other Google Cloud services, accelerator availability might differ. For those services, see the following documentation:

  • Vertex AI: accelerator locations
  • Cloud Run: regions that support GPUs
  • Confidential Computing: zones that support GPUs

Zones that support GPUs

Google Cloud offers GPU resources in multiple locations worldwide. These locations consist of the standard regions and zones, which you can read about on the Regions and zones page. Each zone offers a variety of GPU versions. When you create resources that use accelerators—such as Compute Engine instances or GKE node pools—you must select a zone where that accelerator type is available.

AI zones

Important: When AI zone visibility is turned off, your Google Cloud project's access to AI zones is restricted. To view and access AI zones, turn on AI zone visibility. Additionally, to use an AI zone, you must have pre-reserved capacity allocated. Contact your Google Cloud account team to secure capacity in an AI zone.

In addition to standard zones, GPUs are available in AI zones. These Google Cloud locations are specifically designed to house resources for large-scale AI and machine learning workloads. AI zones offer access to GPU machine types, and might also offer other non-accelerator machine types to support the primary AI and machine learning workloads that run on the accelerators. To learn more about these specialized zones, see About AI zones. To view accelerator availability by zone type, use the Select a zone type filter.

Limited availability regions and zones

Important: This section lists GPU machine types that are restricted, meaning they either require account team approval due to limited capacity, or are available only in specific zones. Review this section before choosing a region or GPU machine type to avoid procurement delays.

  • For A3 Mega (NVIDIA H100) machine types, the following regions and zones are available with limited capacity. To access these regions and zones, contact your account team.

    • Sydney, Australia, APAC: australia-southeast1-c
    • St. Ghislain, Belgium, Europe: europe-west1-b,c
    • Council Bluffs, Iowa, North America: us-central1-b

  • For A3 High (NVIDIA H100) machine types, the following regions and zones are available with limited capacity. To access these regions and zones, contact your account team.

    • St. Ghislain, Belgium, Europe: europe-west1-b

  • For A2 Standard (NVIDIA A100 40GB) machine types, the a2-megagpu-16g machine is only available in the following regions and zones:

    • Iowa, North America: us-central1-a,b,c,f
    • Netherlands, Europe: europe-west4-a,b
    • Singapore, APAC: asia-southeast1-c

  • For G4 (NVIDIA RTX PRO 6000) machine types, the machine types that have less than one GPU attached, such as g4-standard-6, g4-standard-12, and g4-standard-24, are only available in Iowa, North America: us-central1-b. For more information about G4 machine types that have fractional GPUs (vGPUs) attached, see G4 machine series.

Feature availability by region and zone

In addition to the availability of specific accelerator models, some related features and configurations have their own regional or zonal restrictions. The following sections outline the availability for these specific features.

Future reservations in calendar mode and Flex-start VMs

For GPUs, future reservations in calendar mode and Flex-start VMs are available in all zones where the GPU machine types are available.

NVIDIA RTX Virtual Workstations

NVIDIA RTX Virtual Workstations (vWS) are supported on the following machine series.

  • G4: you can enable NVIDIA RTX PRO 6000 vWS on these machine types.
  • G2: you can enable NVIDIA L4 vWS on these machine types.
  • N1: you can enable NVIDIA T4 or V100 vWS GPUs on these machine types.

For these machine types, vWS is supported in any zone where the machine type is available.

Local SSD

For all GPU machine types, Local SSD disks are available in the same zones as the machine type with the following exceptions:

  • N1+V100: Local SSD disks aren't available in the us-east1-c zone.
  • N1+P4: Local SSD disks are only supported in zones us-central1-c and northamerica-northeast1-b.
