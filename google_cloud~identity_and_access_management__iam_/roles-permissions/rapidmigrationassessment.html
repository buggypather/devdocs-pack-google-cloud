This page lists the IAM roles and permissions for Rapid Migration Assessment. To search through all roles and permissions, see the role and permission index.

Service agent roles

Service agent roles should only be granted to service agents.

Role Permissions

RMA Service Agent

(roles/rapidmigrationassessment.serviceAgent)

Gives RMA service account access to MC resources.

Warning: Do not grant service agent roles to any principals except service agents.
