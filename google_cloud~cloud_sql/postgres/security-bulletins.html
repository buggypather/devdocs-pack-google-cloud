Security Bulletins

This page lists security bulletins for Cloud SQL.

To get the latest security bulletins delivered to you, add the URL of this page to your feed reader, or add the feed URL directly: https://docs.cloud.google.com/feeds/cloud-sql-security-bulletins.xml

June 5, 2020

Description Severity Notes

PostgreSQL 9.6 minor version is upgraded to 9.6.16. PostgreSQL 10 minor version is upgraded to 10.11. PostgreSQL 11 minor version is upgraded to 11.6. PostgreSQL 12 minor version is upgraded to 12.1. Refer to the PostgreSQL Security Information for information about specific vulnerabilities addressed in the update.

Cloud SQL impact

Cloud SQL for PostgreSQL instances were automatically updated as part of the maintenance update.

What should I do?

No action is required by you.
