BigQuery Data Transfer Service roles and permissions

This page lists the IAM roles and permissions for BigQuery Data Transfer Service. To search through all roles and permissions, see the role and permission index.

BigQuery Data Transfer Service roles

BigQuery Data Transfer Service offers the following service agent roles. Service agent roles should only be granted to service agents.

Role Permissions

BigQuery Data Transfer Service Agent

(roles/bigquerydatatransfer.serviceAgent)

Gives BigQuery Data Transfer Service access to start BigQuery jobs in consumer project.

Warning: Do not grant service agent roles to any principals except service agents.
