PDF classification categories

Preview

This feature is subject to the "Pre-GA Offerings Terms" in the General Service Terms section of the Service Specific Terms. Pre-GA features are available "as is" and might have limited support. For more information, see the launch stage descriptions.

This page lists all supported content categories that the pdf-classification model can return when evaluating PDF documents with object enrichments.

When Cloud Storage evaluates an eligible PDF document, the model assigns one or more category paths and confidence scores in the pdfClassificationCategoryList.categories[] array. You can use these exact category strings to filter and aggregate your documents in BigQuery.

Taxonomy structure

Categories are formatted as exact English strings structured hierarchically with forward slashes (/) separating category depth:

  • Top-level verticals: Broad subject domains (such as /Finance, /Law & Government, or /Computers & Electronics).
  • Subcategories: Specific subjects within a vertical (such as /Finance/Accounting & Auditing/Tax Preparation & Planning).
  • /Other subcategories: Categories for content that aligns with a parent category but doesn't fit into any specific child subcategory.

The taxonomy is organized into the following top-level verticals:
