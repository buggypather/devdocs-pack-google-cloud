About the console (federated)

The Google Cloud Workforce Identity Federation console, also known as the console (federated), available at https://console.cloud.google/, lets workforce users access Google Cloud products that support Workforce Identity Federation. Because this console shows only supported products, fewer Google Cloud services appear, and individual product interfaces might have additional restrictions.

To learn more about supported products and related limitations, see Identity federation: supported products and limitations.

Access issues

If you have trouble signing in to the console (federated), we recommend that you first contact your organization's security administrator.

Access the full Google Cloud console

Users with a Google Account and appropriate privileges can access the full Google Cloud console at https://console.cloud.google.com/.
