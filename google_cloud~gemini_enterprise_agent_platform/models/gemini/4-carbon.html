Gemini 4 Carbon

Gemini 4 Carbon is Google's frontier model that excels at deep work in complex, real-world tasks across domains including coding, finance, legal, cybersecurity, and science. Gemini 4 Carbon is a Google Frontier Model subject to Section 34 of the Service Specific Terms (for details, see Abuse monitoring).

4 Carbon differs from earlier Gemini models in the following ways:

  • Unified input and output token limit and long decodes: 4 Carbon has a unified 1,048,576-token limit that includes both input and output tokens (where output includes thinking, function calls, and the final response) across all supported API surfaces (the GenerateContent API, the Interactions API, and the OpenAI compatibility Chat Completions API). A single foreground segment generates up to 65,536 output tokens when streaming (or 32,768 tokens when non-streaming). On both the Interactions API and the GenerateContent API (v1beta1), you can extend output up to 1,048,576 tokens (minus your input tokens) using long decodes: the Google Gen AI SDK and Agent Studio handle continuation_token automatically across segments, or you can use background=true on the Interactions API or pass continuation_token in a custom continuation loop (known issue: continuation_token is supported only in the v1beta1 API, which the Google Gen AI SDK uses by default). For details, see the developer's guide to Gemini 4 Carbon.
  • Thinking levels: 4 Carbon supports thinking levels LOW, MEDIUM (default on gemini-4-carbon), and HIGH (default on gemini-4-carbon-cyber-permissive). Setting thinking_budget or thinking_level="MINIMAL" returns an HTTP 400 validation error.
  • Sampling parameters: Custom values for sampling parameters (temperature, top_p, and top_k) are ignored.
  • Context caching: 4 Carbon supports implicit caching only (4,096-token minimum), with durable caching enabled by default. Explicit context caching isn't supported.
  • Office and OpenDocument file inputs: In addition to PDF (application/pdf) and plain text (text/plain), 4 Carbon accepts Microsoft Office (.docx, .dotx, .doc, .pptx, .ppt, .xlsx, .xls) and OpenDocument (.odt, .odp, .ods) files inline or from Cloud Storage on both the GenerateContent API and the Interactions API.
Note: To maintain platform reliability, capacity, and security, Gemini 4 Carbon is available to verified enterprise customers in select regions.

Gemini 4 Carbon for cyber

Gemini 4 Carbon for cyber is a version of Gemini 4 Carbon for defensive cybersecurity use cases, such as vulnerability discovery, reverse engineering, exploit verification, and patch generation. Gemini 4 Carbon for cyber is a Google Frontier Cyber Model subject to Section 31 of the Service Specific Terms (for details, see Abuse monitoring).

Gemini 4 Carbon for cyber is generally available on Gemini Enterprise Agent Platform behind an allowlist. To request access, contact your Google team or apply through the Fairwind Program. Access to earlier Gemini Cyber models (such as Gemini 4 Argon Cyber Permissive or Gemini 3.8 Flash Cyber) doesn't carry over; you must apply separately.
