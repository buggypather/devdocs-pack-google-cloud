About Storage Intelligence

Note: Google Cloud offers a 30-day introductory trial for Storage Intelligence. To evaluate recommendations and explore your storage usage before subscribing, see 30-day introductory trial for Storage Intelligence.

Storage Intelligence provides centralized visibility and control over your Cloud Storage data at scale. Instead of managing individual buckets with custom scripts, you can govern storage across your entire resource hierarchy to identify cost savings, analyze usage trends, monitor security and compliance, and automate bulk operations.

To get started, see Configure and manage Storage Intelligence.

Storage Intelligence use cases

Storage Intelligence helps you accomplish two primary operational tasks:

  • Analyze and optimize your storage
  • Manage and automate storage operations at scale

Analyze and optimize your storage

To evaluate your data distribution, track usage trends, and discover cost savings, you can do the following:

  • Track storage trends, security and compliance, and recommendations: Use Storage Intelligence advisor to monitor capacity growth, detect usage anomalies, and identify cost-saving opportunities across your organization, folders, or projects. You can also evaluate whether objects comply with your bucket encryption policies (Preview).
  • Query metadata and activity by using SQL: Use Storage Insights datasets to generate queryable metadata and activity indexes provided as BigQuery linked datasets. You can analyze data distribution, audit access patterns, and evaluate storage costs across your entire resource hierarchy.
  • Ask questions by using AI: Use data storage insights with Gemini Cloud Assist to ask natural-language questions about your storage environment. When you configure Storage Insights datasets, you can prompt Gemini to identify your largest buckets without Autoclass enabled or list objects in the Standard storage storage class smaller than 50 MB.
  • Audit bucket inventory: Use inventory reports to generate per-bucket reports that catalog objects and metadata. A Storage Intelligence subscription includes inventory reports and covers all object scan fees.

Manage and automate storage operations at scale

To manage buckets across regions and run operations at scale without custom scripts, you can do the following:

  • Relocate buckets across regions: Use bucket relocation to move buckets between geographic locations with minimal downtime, preserving bucket names, object metadata, and storage classes.

  • Run operations across billions of objects: Use Storage batch operations to automate bulk tasks, such as updating metadata, transforming storage classes, or deleting expired objects, without writing custom scripts.

Configuration options

When you configure Storage Intelligence, you make three decisions:

  1. Choose a resource level in your Google Cloud resource hierarchy.
  2. Apply bucket filters to include or exclude specific buckets by location or name.
  3. Select an edition configuration to control activation for each resource.

Choose a resource

You can configure Storage Intelligence at different levels of your Google Cloud resource hierarchy. The configuration automatically applies to all buckets and objects within that resource:

  • Organization: Applies to the entire organization. All current and new folders and projects inherit this configuration unless overridden.
  • Folder: Applies to all current and new projects in the folder unless overridden.
  • Project: Applies to all current and new buckets in the project. Configuring at the project level is ideal for teams that manage storage independently.

Apply bucket filters

Bucket filters let you control which buckets Storage Intelligence manages, helping you focus analysis on relevant data and reduce processing costs:

  • Filter by location: Include or exclude specific Google Cloud locations to focus on high-activity regions or omit regulated data.
  • Filter by name: Include or exclude buckets that match a regular expression pattern, such as environment prefixes or department identifiers.

For instructions on applying filters, see Configure Storage Intelligence.

Select an edition configuration

The edition configuration controls whether Storage Intelligence capabilities are active for a resource:

  • INHERIT: Inherits the edition configuration of the parent resource.
  • STANDARD: Enables Storage Intelligence capabilities. STANDARD is the default edition when you configure Storage Intelligence for a resource.
  • DISABLED: Disables Storage Intelligence for the specified resource. Child resources inherit the disabled state unless explicitly configured with STANDARD or INHERIT.
  • TRIAL: Activates the 30-day introductory trial for Storage Intelligence.
