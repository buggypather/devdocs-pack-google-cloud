Method: projects.locations.reportConfigs.list

Lists the inventory report configurations in a given project for a given location.

HTTP request

GET https://storageinsights.googleapis.com/v1/{parent=projects/*/locations/*}/reportConfigs

The URL uses gRPC Transcoding syntax.

Path parameters

Parameters
parent

string

Required. Parent value for ListReportConfigsRequest

Query parameters

Parameters
pageSize

integer

Requested page size. Server may return fewer items than requested. If unspecified, the server picks the default value.
pageToken

string

A token identifying a page of results the server should return.
filter

string

Filtering results
orderBy

string

Hint for how to order the results

Request body

The request body must be empty.

Response body

Response message for reportConfigs.list

If successful, the response body contains data with the following structure:

JSON representation 
{
  "reportConfigs": [
    {
      object (ReportConfig)
    }
  ],
  "nextPageToken": string,
  "unreachable": [
    string
  ]
}
Fields
reportConfigs[]

object (ReportConfig)

The list of ReportConfig
nextPageToken

string

A token identifying a page of results the server should return.
unreachable[]

string

Locations that could not be reached.
