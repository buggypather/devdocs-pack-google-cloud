Google Cloud Support roles and permissions

This page lists the IAM roles and permissions for Google Cloud Support. To search through all roles and permissions, see the role and permission index.

Google Cloud Support roles

Role Permissions

Support Administrator

(roles/cloudsupport.admin)

Allows management of a support account and support cases. See the Cloud Support documentation for more information.

Lowest-level resources where you can grant this role:

  • Organization

Support Viewer

(roles/cloudsupport.viewer)

Read-only access to details of a support account. This does not allow viewing cases. See the Cloud Support documentation for more information.

Lowest-level resources where you can grant this role:

Advisory Support Editor

(roles/cloudsupport.advisorySupportEditor)

Full read-write access to advisory support cases applicable for Cloud Customer Care.

cloudasset.assets.searchAllResources

cloudsupport.properties.get

resourcemanager.projects.get

resourcemanager.projects.list

Advisory Support Viewer

(roles/cloudsupport.advisorySupportViewer)

Read-only access to advisory support cases applicable for Cloud Customer Care.

cloudsupport.properties.get

resourcemanager.projects.get

resourcemanager.projects.list

Support Subscription Editor

(roles/cloudsupport.supportSubscriptionEditor)

Full read-write access to support event subscriptions.

resourcemanager.organizations.get

Support Subscription Viewer

(roles/cloudsupport.supportSubscriptionViewer)

Read-only access to support event subscriptions.

resourcemanager.organizations.get

Tech Support Editor

(roles/cloudsupport.techSupportEditor)

Full read-write access to technical support cases (applicable for Cloud Customer Care and Maps support). See the Cloud Support documentation for more information.
