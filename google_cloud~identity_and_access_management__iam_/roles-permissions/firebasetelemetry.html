Firebase Telemetry roles and permissions

This page lists the IAM roles and permissions for Firebase Telemetry. To search through all roles and permissions, see the role and permission index.

Firebase Telemetry roles

Firebase Telemetry offers the following service agent roles. Service agent roles should only be granted to service agents.

Role Permissions

Firebase Telemetry Service Agent

(roles/firebasetelemetry.serviceAgent)

Access to Cloud Storage, Cloud Monitoring, and Cloud Logging for Firebase Telemetry.

Warning: Do not grant service agent roles to any principals except service agents.
