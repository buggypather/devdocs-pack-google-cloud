Integration with Google Cloud services and tools

This page describes some of the other Google Cloud products that are integrated with Cloud Storage.

For a list of Google Cloud products that are integrated specifically with Cloud Storage FUSE, see Cloud Storage FUSE integrations with Google Cloud products.

Product Links
AI Hypercomputer Use Cloud Storage to store large scale training data for GPU and TPU clusters, and use Cloud Storage FUSE for most artificial intelligence (AI) and machine learning (ML) use cases. For more information, see Storage services.

  • Import SQL data from Cloud Storage into AlloyDB
  • Export SQL data from AlloyDB to Cloud Storage
