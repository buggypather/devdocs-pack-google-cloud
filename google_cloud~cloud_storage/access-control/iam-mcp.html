IAM permissions for Cloud Storage MCP server methods

To run Cloud Storage MCP server methods, you need access to the target Cloud Storage resources. You manage access control by granting Identity and Access Management (IAM) roles to principals, such as users, groups, and service accounts. Each role contains a set of permissions. If you want to create custom roles with specific permissions, this document lists the permissions that are required for each MCP server method.

Method Required IAM Permissions
create_bucket mcp.tools.call
storage.buckets.create
delete_bucket mcp.tools.call
storage.buckets.delete
delete_object mcp.tools.call
storage.objects.delete
get_object_metadata mcp.tools.call
storage.objects.get
list_buckets mcp.tools.call
storage.buckets.list
list_objects mcp.tools.call
storage.objects.list
read_object mcp.tools.call
storage.objects.get
write_text mcp.tools.call
storage.objects.create
